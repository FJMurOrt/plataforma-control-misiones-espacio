# Plataforma de Control de Misiones Espaciales

Este proyecto es una plataforma de control y monitorización de misiones espaciales desarrollada como práctica personal en DevOps y automatización.

## Tecnologías

- Python
- FastAPI
- Docker
- GitLab CI/CD
- SonarQube
- Jenkins
- Ansible
- LangChain
- Gemini

## Objetivo del proyecto

El proyecto de lo que trata es de simular una plataforma sencilla para gestionar misiones espaciales, naves, telemetría e incidencias. Sin embargo, mi verdadera intención es poder incorporar herramientas DevOps para automatizar el desarrollo, análisis, construcción y despliegue de la aplicación. Además de las herramientas DevOps, también se integra un asistente basado en inteligencia artificial utilizando LangChain y Gemini.
